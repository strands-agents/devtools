# Goals: first-response

- A disposition from the six is present; for a bug report, reproduction was attempted in the
  sandbox with output shown, and any "cannot reproduce" shows a Path B derived attempt.
- Priority present for confirmed bugs only; `N/A` otherwise.
- Duplicate search done (or absence stated); ticket and draft comment present.
- Nothing posted unless the user asked.
- One valid `work-product` block last, `kind: "first-response"`, no `priority` on an unconfirmed
  verdict.
